How QR codes work

        
A QR code stores text as a grid of dark and light squares called modules. The three large squares in the corners tell a camera where the code is and which way up it is. The rest holds your data plus extra error-correction data, which lets a phone read the code even when part of it is dirty, torn or covered by a logo.


This generator follows the international standard ISO/IEC 18004. It picks the smallest code size that fits your content, adds error correction, and tries all eight standard patterns ("masks") to choose the one that is easiest to scan.

When the content leaves room, the generator raises the level for free, so you get extra robustness without a bigger code.

      

    


    

      
Static codes never expire. Dynamic codes can.

      

        
Many "free" QR sites make dynamic codes: the code points to their own short link, which then redirects to your page. That lets them show statistics, but it also means the code stops working if you stop paying, if the free trial ends or if the company closes. Printed menus, flyers and business cards have been left with dead codes this way.


Every code made here is static: your link, Wi-Fi details or contact card are stored in the pattern itself. There is no redirect, no account and no tracking, and the code works for as long as the destination exists. To change where a printed code goes, point it at a page you control, such as your own website, and change that page instead.

      

    

    

      
What you can put in a QR code

      

        
    

  • Link: any web address. Include https:// so phones open it straight away.
    • 

  • Wi-Fi: guests scan to join your network without typing the password. Supported by the camera apps on iPhone (iOS 11+) and Android 10+.
    • 

  • Contact (vCard): name, company, phone, email and website, saved to the phone's contacts in one tap. Ideal for business cards.
    • 

  • Email: opens a new email with the address, subject and message filled in.
    • 

  • Call and SMS: starts a call or a text message to your number. Use the full international format, such as +44 or +91.
    • 

  • Text: any short message, up to about 2,900 characters at the lowest error correction.
    • 



Any language works, including Chinese, Arabic and Hindi, because text is stored as UTF-8.

      

    

    

      
Design and printing tips

      

        
    

  • Keep contrast high. Dark dots on a light background scan best. The tool warns you when the contrast drops below 4:1 or when the colours are inverted.
    • 

  • Keep the quiet zone. The white border of four modules helps the camera find the code. Do not crop it off.
    • 

  • Size for the distance. A common rule is that the code should be at least one tenth of the scanning distance. For a poster read from 2 metres, make it 20 cm wide. On business cards, 2 cm is the practical minimum.
    • 

  • Logos: keep the logo small (the tool uses about 5% of the area) and use High error correction, which is set automatically.
    • 

  • Print in SVG. SVG is a vector file, so it stays perfectly sharp at any size. Use PNG for websites, slides and messages.
    • 

  • Always test. In Chrome and Edge the tool scans your design in the browser and confirms it reads back exactly. Test the printed result with two or three different phones as well.
    • 

  • Short links make simpler codes. Fewer characters mean fewer, larger squares that scan from further away.
    • 


      

    

    

      
Privacy and safety

      

        
Your content is turned into a QR code inside this browser. Nothing is uploaded, and the Wi-Fi password is never saved, even in your own browser. Other settings are remembered on this device only.


When you scan codes yourself, check the address your phone shows before opening it. Fake QR stickers on parking meters and posters are a common scam, sometimes called "quishing".

      

    


    

      
QR code questions

      

        
Is this QR code generator really free?
Yes. There is no sign-up, no watermark, no limit and no expiry. The codes are static, so they keep working for ever.

        
Do QR codes expire?
Static QR codes, like the ones made here, never expire because the content is stored in the code itself. Dynamic codes from some sites stop working if the subscription or redirect service ends.

        
How do I make a QR code for Wi-Fi?
Choose Wi-Fi, enter the network name and password and pick the security type. Guests scan the code with their phone camera to join without typing the password.

        
Can I add a logo to my QR code?
Yes. Upload a PNG, JPG, WebP or SVG logo. It is placed in the centre and error correction is raised to High so the code still scans. Use the scan test to confirm it.

        
What size should a printed QR code be?
At least 2 cm (0.8 inches) wide for close-up use such as business cards, and about one tenth of the scanning distance for posters. Download the SVG for print so it stays sharp.

        
Why is my QR code not scanning?
The usual causes are low contrast, light dots on a dark background, a cropped white border, a logo that is too large or a code printed too small. The tool warns about the first two and tests scanning in Chrome and Edge.

        
Can I track how many people scan my QR code?
Not with a static code, because there is no redirect. You can add tracking parameters to your link, such as utm_source=flyer, and see the visits in your website analytics.
